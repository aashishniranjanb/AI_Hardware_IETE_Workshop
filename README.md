# AI Hardware — IETE Club Web Deck

Interactive presentation starter for the 09 October 2026 hands-on workshop.

## Stack
- React + Vite
- GSAP
- SVG/CSS architecture visuals
- Three.js / React Three Fiber dependency ready for 3D scenes
- HTML5 video folder ready at `public/videos`

## Run
```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Presenter controls
- Right Arrow / Space — next scene
- Left Arrow — previous scene
- F — fullscreen
- B — blackout
- Click controls bottom-right also work
